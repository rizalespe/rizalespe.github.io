Beberapa istilah yang akan Anda temui

Tidak perlu dihafal — kembali ke sini kapan saja

Dashboard
Halaman yang merangkum data dalam bentuk angka ringkas, tabel, dan grafik supaya mudah dibaca sekilas.
Link / URL
Alamat sebuah halaman di internet, misalnya https://docs.google.com/…
Publish to web
Fitur Google Sheets untuk membuat versi "baca saja" dari data Anda yang bisa diakses lewat link.
TSV
Salah satu format data teks. Anda tidak perlu memahaminya — cukup pilih format ini saat diminta.
Prompt
Pesan atau perintah yang Anda ketik ke Claude.
Artifact
Halaman web yang dibuat Claude dan bisa dibuka lewat link sendiri.
1

Publish Google Sheets ke Web

Membuat link khusus agar data Anda bisa dibaca oleh dashboard

a
Buka Google Sheet Anda, klik menu File → Share → Publish to web
b
Pilih sheet/tab yang berisi data (bukan "Entire Document"), lalu ganti pilihan format (biasanya tertulis "Web page") menjadi Tab-separated values (.tsv)
c
Klik Publish → OK. Salin link yang muncul — inilah "alamat" data Anda. Simpan dulu di catatan, nanti dipakai di Langkah 2.
d
Cek dulu: tempel link tersebut di tab browser baru. Jika muncul halaman polos berisi tulisan data Anda (tanpa tampilan tabel seperti di Sheets), berarti berhasil. Di beberapa browser, file data justru langsung terunduh — itu juga tanda berhasil.
⚠️ Siapa pun yang punya link ini bisa melihat data Anda. Jangan publish data rahasia atau data pribadi orang lain, seperti NIK, nomor HP, alamat, atau nilai mahasiswa.
↓
2

Minta Claude membuat dashboard

Salin pesan di bawah, lengkapi bagian yang ditandai, lalu kirim ke Claude

💡 Klik tombol Salin, tempel di kolom chat Claude, lalu ganti teks dalam kurung siku […]: isi dengan link dari Langkah 1, dan 3–5 baris pertama data Anda (termasuk baris judul kolom) yang disalin langsung dari Google Sheets. Contoh baris ini membantu Claude memahami isi data Anda.
Prompt 1 — Buat dashboard pertama
Saya punya data di Google Sheets yang sudah dipublish ke web. Ini link-nya (format TSV): [TEMPEL LINK DARI LANGKAH 1 DI SINI] Ini beberapa baris pertama datanya: [TEMPEL 3–5 BARIS DATA DI SINI] Saya bukan orang IT. Tolong buatkan dashboard berupa halaman web (HTML) yang: - Mengambil data dari URL tersebut otomatis saat halaman dibuka - Menampilkan ringkasan singkat (jumlah data, dll) - Menampilkan tabel lengkap dengan fitur pencarian - Tampilan rapi dan profesional - Ada tombol Reload untuk memperbarui data Publish sebagai artifact, lalu jelaskan cara memakainya dengan bahasa sederhana.
Prompt 2 — Jika dashboard muncul tapi datanya tidak tampil
Dashboard-nya muncul, tapi data dari Google Sheets tidak tampil (kemungkinan error CORS). Tolong perbaiki dengan cara: 1. Coba ambil data langsung dari link dulu 2. Jika gagal, coba lewat proxy allorigins.win, lalu corsproxy.io 3. Jika semua gagal, simpan salinan data langsung di dalam dashboard sebagai cadangan agar tetap bisa tampil 4. Beri tanda kecil: hijau jika data terbaru dari Sheets, kuning jika memakai data cadangan
⚠️ Cara nomor 2 di pesan ini mengirim data Anda lewat layanan milik pihak lain (allorigins.win, corsproxy.io). Tidak masalah untuk data yang memang boleh dilihat umum, tapi jangan pakai untuk data pribadi.
↓
3

Tambah fitur sesuai kebutuhan

Tambahkan satu fitur per pesan

💡 Minta satu hal per pesan — hasilnya lebih baik daripada meminta banyak sekaligus. Ganti [NAMA KOLOM] dengan judul kolom yang persis sama seperti di Google Sheets Anda, misalnya "Program Studi" atau "Nilai Akhir".
Tambah grafik
Tambahkan grafik batang yang membandingkan nilai kolom "[NAMA KOLOM]" untuk setiap "[NAMA KOLOM LAIN]".
Tambah filter dropdown
Tambahkan filter dropdown untuk kolom "[NAMA KOLOM]" agar saya bisa menampilkan hanya data dari satu kategori.
Beri warna pada nilai tertentu
Di kolom "[NAMA KOLOM]", warnai teks: hijau jika nilainya "Ya" atau di atas 80%, merah jika "Tidak" atau di bawah 60%, abu-abu untuk yang lain.
Ubah tampilan
Ubah tampilan dashboard menjadi berlatar terang, dengan huruf yang lebih besar dan mudah dibaca saat ditampilkan di proyektor.
↓
4

Publish dan bagikan

Dashboard Anda jadi link yang bisa dibuka orang lain

a
Jika Claude belum memberikan link, kirim pesan: "Publish sebagai artifact."
b
Salin link yang muncul — formatnya: claude.ai/artifact/xxxxx
c
Awalnya dashboard hanya bisa dibuka oleh Anda sendiri. Klik tombol Share dan ubah aksesnya agar orang lain bisa membukanya. Untuk memastikan, buka link di jendela penyamaran/incognito (tekan Ctrl+Shift+N di Chrome, atau Cmd+Shift+N di Mac).
✅ Jika data di Sheets diupdate, cukup buka dashboard dan klik Reload — data terbaru akan diambil. Perubahan di Sheets bisa butuh beberapa menit sebelum muncul di URL yang dipublish.

Masalah umum & solusinya

Masalah Yang harus dilakukan
Dashboard kosong / tidak ada data Ulangi langkah Publish to web. Pastikan pilih format TSV, bukan CSV atau lainnya.
Dashboard muncul, tapi data tidak tampil atau ada pesan error Kirim Prompt 2 di Langkah 2. Jika masih gagal, salin pesan error yang terlihat dan kirim ke Claude.
Data lama, tidak update Tunggu beberapa menit (Google butuh waktu memperbarui versi publish), lalu klik Reload. Jika tidak ada tombol, minta Claude menambahkannya.
Dashboard tidak rapi di HP Kirim ke Claude: "Perbaiki tampilan agar rapi saat dibuka di HP."
Link artifact tidak bisa dibuka orang lain Cek pengaturan Share artifact — pastikan aksesnya sudah dibuka, bukan privat. Uji ulang di jendela incognito.
Menu "Publish to web" tidak bisa dipakai Akun Google kantor/kampus kadang membatasi fitur ini. Hubungi admin, atau salin data ke spreadsheet di akun Google pribadi.
