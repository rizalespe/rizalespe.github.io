Tanda tangan digital untuk tim

Sigil menandatangani dan memverifikasi berkas pakai OpenPGP, sepenuhnya di browser kamu. Private key tidak pernah dikirim ke server mana pun — semuanya berjalan lokal di perangkatmu.

Alur kerja

  1. Buat Kunci — sekali saja per orang. Simpan private key baik-baik, publish public key ke folder /keys di repo ini.
  2. Sign — upload berkas + private key kamu, dapatkan berkas signature (.sig).
  3. Verify — siapa pun di tim bisa cek keaslian berkas + signature terhadap public key yang terdaftar.

Public key terdaftar

Daftar ini dibaca dari keys/manifest.json. Tambahkan entri baru di sana setiap ada anggota baru.
